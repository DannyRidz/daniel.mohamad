# Portfolio design

Source: authored from the owner's professional redesign brief.

## Character

Swiss editorial design. White and neutral surfaces, a single blue accent, Helvetica throughout, generous but purposeful spacing, asymmetric columns and fine rules. Project evidence provides the imagery. No stock portraits or invented app screens.

## Build mandate

Make Daniel's engineering work the visual center. A large left aligned introduction and a compact numbered project index establish the page. Broad project previews alternate with concise engineering explanations. Preserve enough breathing room for a recruiter to scan the page without losing the technical substance.

## Tokens and components

`styles.css` owns all color, spacing, type and motion tokens. Shared buttons, tags, project rows, section labels and link groups keep the surface consistent. Blue communicates links and emphasis; text always names status explicitly.

## Responsive behavior

The header wraps without a menu. Hero, projects and section grids become a single column below the tablet breakpoint. At 320px, actions and long contact text wrap. Preview images retain their aspect ratio. Native disclosures show engineering notes on demand.

## Do and avoid

Use real screenshots and clear provenance. Keep copy concrete and headings descriptive. Keep the interface usable with CSS alone. Avoid metrics without evidence, decorative code fragments, animated reveals, color only meaning, remote fonts and dependencies.
