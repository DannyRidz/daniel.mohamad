Developer tools · AI integration

Cartograph

Find your way through an unfamiliar codebase.

I built an interactive explorer for public JavaScript and TypeScript repositories. It maps real imports so developers can follow dependencies, trace potential change impact, and ask questions about repository structure.

  • Parsed imports with ts-morph and TypeScript module resolution, reporting unresolved connections explicitly.
  • Shared graph traversal between the interactive map and the repository Q&A tools.
  • Connected AI explanations to recorded repository facts, with organization access enforced in Postgres.

Engineering notes Architecture, decisions & boundaries

Separate facts from explanations

A standalone parser resolves imports before AI is called. Pure graph functions calculate dependencies and dependents for both the map and agent tools, so structural answers use the same underlying data.

Make the limits visible

Skipped files and unresolved imports remain visible. Change impact is graph reachability, not a prediction of runtime failure. Support is limited to public JavaScript and TypeScript repositories.

Keep access scoped

Clerk organizations and Supabase row-level security control stored analyses. Short-lived grants scope agent lookups to one analysis. Recorded agent cases are checked against independent parser output.

Mobile application · Voice AI

RidzTalk

Two languages. One spoken conversation.

I built a two-way voice translator for people who need to understand each other without typing back and forth. It brings speech transcription, translation, and voice playback into a mobile conversation interface.

  • Integrated OpenAI Realtime audio over WebRTC, with transcript and translation event handling.
  • Used Supabase authentication and Edge Functions for server-side AI calls and session credentials.
  • Packaged the React app with Capacitor for Android and iOS, with subscriptions and usage handling.

Engineering notes Audio, backend & mobile delivery

Preserve speech order

Final transcripts can finish out of order. The translation queue reserves each speech turn's position, fills it when the transcript arrives, and carries the source identity into the translation request. A public code sample makes this behavior inspectable.

Keep provider credentials on the server

Supabase Edge Functions issue short-lived Realtime credentials after usage checks. The client uses those credentials for the audio session rather than receiving the main provider API key.

Account for platform differences

A shared React interface runs inside Capacitor native projects. Audio permissions, playback, RevenueCat subscriptions and usage logic have separate implementation and test coverage. Android is publicly listed; no public iOS release is claimed.

Engineering approach & limits
